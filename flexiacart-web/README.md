# FlexiaCart.com — Official E-Commerce Web Application 🛒🚀
**Evolved from Campus Market! Serving University Students & City Residents across Nigeria with flexible prices, smart bundles, and 30-minute express delivery.**

---

## 🌟 What is FlexiaCart?
FlexiaCart is a world-class, dual-audience online marketplace built with **Next.js 14/15 (App Router)**, **TypeScript**, and **Tailwind CSS**. 

It removes the student-only boundary of *Campus Market* by offering explicit **Campus Dorm Delivery (₦500)** and **City Residential Delivery (₦1,200)** toggles anywhere on the platform.

---

## 🚀 Key Features Included
- **Storefront Marketplace (`/`)**: Category pills, active search query filtering, `FLEXIA10` promo banner, and product grid.
- **Product Detail Pages (`/product/[slug]`)**: Verified 4.9★ reviews, strikethrough discount pricing, and delivery time estimator.
- **Smart Value Bundles (`/bundles` - Screen 11)**: Pre-packed discounted combos (*Dorm Freshers Starter Kit - ₦18,500*, *Bachelor Provision Combo - ₦49,500*).
- **30-Min Express Hub (`/express` - Screen 14)**: Emergency urgent delivery mode for phone chargers, midnight snacks, and exam essentials.
- **FlexiRewards Club (`/rewards` - Screen 13)**: Gamified loyalty dashboard with "FlexiPoints" and WhatsApp referral link generator (*"Give ₦1,500 / Get ₦1,500"*).
- **Shopping Cart Drawer & Promo Code Engine**: Instant state updates with `FLEXIA10` 10% OFF discount validation.
- **Secure Nigerian Checkout (`/checkout`)**: Supports OPay/PalmPay Automated Transfer, Paystack/Card, and Pay on Delivery.

## 🛠️ How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/flexiacart.git
   cd flexiacart
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser!
